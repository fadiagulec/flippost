📋 The 10-Point Posting Playbook

  1. Hook in frame one. If the first second doesn't confront, the rest never gets watched.
  2. Say the hook AND show it. Spoken + on-screen text doubles retention.
  3. Cut every breath. No pauses in the first 10 seconds — dead air is a swipe.
  4. One idea per post. Two ideas = zero saves. Split it into two posts.
  5. Payoff before the CTA. Deliver the value, then ask for the follow — never the reverse.
  6. Caption = second hook. Don't repeat the video's first line; add a new angle.
  7. Score it before posting. Run it through ViralScore — fix anything under 70 on Hook Strength.
  8. Hashtags: 3 broad + 5 niche + 2 micro. All-broad is invisible; all-micro is a dead end.
  9. Reply to the first 10 comments within an hour. Early engagement decides the second wave.
  10. Repost winners in 6 weeks. If it worked once, a new hook on the same body works again.
